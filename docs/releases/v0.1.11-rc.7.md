## Features

- `append-clean-card` 将思考与工具分成独立时间线，最终回答保持居中。
- 合并转发会展开嵌套引用和可访问的父消息，保留完整上下文。
- 运行中卡片空闲 5 秒自动刷新，长推理和工具执行持续可见。

- 状态栏在后台刷新最新版本，首次使用也能提示可升级版本。
- 无法访问的引用父消息会明确标记，不会中断后续回答。
