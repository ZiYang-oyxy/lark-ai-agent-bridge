# v0.1.13-rc.6

## Breaking Changes

- 无。

## Features

- 引用消息按发送者主体分档标注：来自另一 bot、来自自己历史、来自普通用户，Agent 不再把外部第一人称当作自己历史状态。
- 群聊里普通消息通过 `/action` 触发的对等命令与卡片点击行为对齐，权限与副作用受同一套白名单约束。
- `local_config.reset` 支持在群里通过消息触发，与其他 `local_config.*` 命令一致。
- 配置持久化底座上线：凭据白名单 `LAB_LARK_*` 环境变量、Config 分区段落盘、secret 只驻内存、`--reset-store` 出厂重置。
- `/status`、`/help` 与升级卡片显示 rc 通道来源，方便区分开发者模式与正式版。

## Bug Fixes

- 修复群里跨分身/跨主体的引用消息把"我起了子代理"这类第一人称叙述带入当前会话导致的幻觉。
- 修复 P2P 里同时发生"转发素材 + @bot"时产生两条独立回复的问题：转发素材延后与后续 @bot 请求合并。
- 修复群 mention_only 场景下"合并转发 + @bot"读不到转发正文，转发内容现随后续 @bot 请求进入 Prompt。
- 修复直接接收的合并转发不展开正文的问题，现在会读取转发中的 CardKit 可见文本与附件上下文。
- 修复 `/action` 消息路径下 CardKit 首次渲染缺 `replyTo` 导致按钮无响应。
- 修复 markdown 分页场景下"停止"按钮返回操作已失效的 bug，取消也能可靠中止。
- 修复 coder / worker 模式回复归类错乱。
