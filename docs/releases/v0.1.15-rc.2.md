## Bug Fixes

- systemd 使用 `Restart=on-failure` 托管 Bridge 时，自升级成功后不再停留在 `inactive (dead)`；Bridge 会让 service manager 拉起受监管的新版本进程。
- 未配置自升级时，`/help` 不再因 Go typed-nil interface 误报“暂时无法检查更新”，而是正确显示自升级未启用。
- Agent launcher 非零退出时优先保留真实 stderr 和进程错误，不再被 stream 缺少 terminal event 的次生错误覆盖。

## Upgrade Notes

- 无配置迁移。从受影响的旧版本首次升级到本 RC 时，重启步骤仍由旧 updater 执行；systemd 部署建议先设置 `Restart=always`，或在 binary 替换后手工启动一次。本 RC 已运行后，后续升级可正常配合 `Restart=on-failure`。
