# v0.1.13-rc.11

## Breaking Changes

- 无。

## Features

- 新增 Agent 请求原始日志：在调用 Agent 前，将最终 Prompt、模型、effort、工作目录等信息写入 `<workdir>/.lark-agent-bridge/agent-requests.jsonl`，便于核对 Bridge 实际转发内容。
- 新增飞书入站原始日志：将长连接事件和卡片回调的原始 payload 写入 `<workdir>/.lark-agent-bridge/feishu-events.jsonl`，便于追踪飞书到 Bridge 的真实输入。两类日志文件均使用 `0600` 权限，写入失败只记录 audit，不阻断消息处理。

## Bug Fixes

- 引用或转发飞书卡片时，可展开表格、标题、字段和按钮链接；“先转发卡片、再回复同一卡片”不再把相同内容重复发送给 Agent。
- 本地 `simulate` 测试使用隔离的 preference store，避免被运行实例的 Agent 偏好污染；同步放宽随机消息 ID 下的稳定 SessionID 断言。

## Upgrade Notes

- `agent-requests.jsonl` 和 `feishu-events.jsonl` 包含完整消息与 Prompt，排障结束后应按实际环境的访问控制和磁盘策略管理。

## Miscellaneous

- 新增统一 Makefile 测试入口，将测试文档统一为 L0-L3 分层，并把 `e2e-real.sh` 拆为注册表驱动的模块化用例。
- 补充测试框架总体设计及 P-VERIFY、P-OBSERVE、P-ENV 三个专项演进方案。
