## Bug Fixes

- **topic 模式只在主会话正文显式 `@bot` 后创建话题**。飞书可能在 P2P 消息中携带 bot mention 元数据，即使用户正文没有显示 `@bot`；旧逻辑只检查 `Mentioned`，会把普通主会话消息 mint 成 `@bot:<message_id>` synthetic topic，并以 `reply_in_thread=true` 回复。新逻辑从 text/post 原始消息内容独立识别 `ExplicitBotMention`：P2P 或群聊主会话没有显式 `@bot` 时，本条消息统一使用 chat root session 和普通聊天回复；显式 `@bot` 仍创建独立 topic，已有 thread 的续聊仍保持 topic 行为。

## Upgrade Notes

- 无需迁移。已保存的全局和群级 `conversation_mode=topic` 配置保持不变；主会话无显式 `@bot` 时只对当前消息临时采用 chat 路由，不会把 topic 偏好写回为 chat。
