# v0.1.13-rc.3

## Breaking Changes

- 无。

## Features

- 话题模式下处理顶层 post 消息时，Bridge 会先创建并绑定话题，再开始 Agent 运行，保证后续回复稳定进入同一话题。

## Bug Fixes

- Codex 运行中的状态栏会从当前 session transcript 读取已生效的实际模型，并在后续流事件到达时刷新；不再只能等待会话结束后的 context sidecar。
- 续聊会采用 session transcript 最新一条模型记录，避免配置变更后仍展示旧轮模型。运行期记录尚不可用时仍显示“同步中”，不会把请求配置误当成实际模型。

## Upgrade Notes

- 无需迁移。升级后新发起的 Codex 任务会自动显示运行期实际模型。
