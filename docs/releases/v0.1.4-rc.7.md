## Bug Fixes

- 修复跑着 rc 版本（如 `0.1.4-rc.N`）的实例在默认 stable 通道下看不到升级到同 core 正式版（如 `0.1.4`）的提示：此前 stable 比较丢弃当前版本的 rc 后缀、只比数字 core，把 rc 误判为「已是最新」。改为按 SemVer 语义（prerelease 严格小于其对应 release）比较，rc 会正确提示升级到对应正式版。「rc 目标不进 stable 通道」的安全边界不变。
