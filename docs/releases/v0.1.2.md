# v0.1.2

## 主要更新
- 飞书结果卡片新增上下文窗口占用率，并用绿、黄、红三色提示剩余容量风险；可用时同时展示已用 token 与窗口总量。
- Claude 与 Codex 均可读取各自的 `context-usage` 数据；数据缺失或无效时自动保留原有 token 展示，不影响消息处理。

## 修复
- 无独立的用户可感知问题修复。

## 升级说明
- 替换二进制并重启 Bridge 即可，无需迁移数据。
- 默认从 `CLAUDE_CONFIG_DIR/context-usage` 和 `CODEX_HOME/context-usage` 读取；也可分别用 `LAB_CLAUDE_CONTEXT_USAGE_DIR`、`LAB_CODEX_CONTEXT_USAGE_DIR` 指定目录。
