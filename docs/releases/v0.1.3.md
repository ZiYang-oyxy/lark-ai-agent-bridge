# v0.1.3

## Breaking Changes

- 无。

## Features

- 新增 topic 级工作目录管理，管理员可通过 `/cd` 与 `/ws save|use|remove` 切换并持久化命名工作区，同时拦截高风险目录。
- 飞书结果卡片可读取 Claude/Codex sidecar 的当前上下文窗口占用率，并展示绿、黄、红容量风险提示。
- Agent 执行失败时保留有界诊断尾部并写入审计记录，便于定位失败原因。
- Release bundle 新增 `AI_INSTALL.md`，提供固定版本和通道 manifest 两种 AI Agent 安装入口。

## Bug Fixes

- 修复旧部署中的 `LAB_CLAUDE_BIN` 被忽略、导致 workspace Claude wrapper 未生效的问题；同时配置时仍由 `E2E_CLAUDE_BIN` 优先。
- 拒绝过期或跨 run 的 sidecar，避免结果卡片显示上一轮上下文数据，并优先使用当前 Codex token 数据。
- 隔离 scheduled、proposal 与 task Agent 会话，避免不同调度任务串用上下文。
- 修复合法 Agent 偏好被 doctor 误判为无效配置，以及 `/cd` 无法创建并切换到缺失目录的问题。

## Upgrade Notes

- 替换二进制并重启服务即可，无需迁移持久化数据；topic 工作目录配置会写入新的 workspace store。
- 如需准确展示上下文窗口占用率，还需同步更新 workspace 的 `bin/claude`、context exporter 与 statusline；仅更新 Bridge 二进制时会回退到估算用量。

## Miscellaneous

- 新增 L0-L3 分层回归编排、秒级本地 smoke 和真实上下文 canary，明确本地验证、发布候选验证与远程 Test 冒烟边界。
- 正式版与 RC 统一使用结构化 Release Note，并加强重复条目、AI 安装指南权限和发布产物校验。
