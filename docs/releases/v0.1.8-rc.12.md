# v0.1.8-rc.12

## Breaking Changes

- 无。

## Features

- 群聊权限支持按群选择 `all_members` 或 `selected_members`。Bot owner/管理员可在目标群使用 `/group-access all|selected` 切换策略，并通过 `/invite member @某人`、`/remove member @某人` 管理指定成员。
- stop、工作目录创建/取消、定时确认/取消和恢复会话选择等敏感 CardKit 操作改为持久化一次性授权。授权绑定操作者、可信 chat、session、action、参数摘要、过期时间和权限策略 revision，并在副作用前原子消费。

## Bug Fixes

- 私聊用户白名单的回复文案现在明确区分“允许响应的用户”和群聊成员策略，避免把两类权限误认为同一作用域。
- 拒绝重放、参数篡改、跨用户、跨会话、过期以及权限策略变更后的旧卡片操作，避免历史卡片绕过当前访问策略。

## Upgrade Notes

- `access.json` 会从 schema v1 自动迁移到 v2；已有允许响应群保持 `all_members`，不会因升级意外拒绝现有群成员。
- 无需手工修改配置。生产启动时若 ActionGrant store 无法打开会 fail-closed，需先修复状态目录权限或路径。

## Miscellaneous

- L1 全量测试、`scripts/verify.sh` 和 Mac Test 真实飞书 L3 均通过；L3 覆盖群白名单、指定成员策略、成员增删、access v2 持久化，以及真实 `create_workdir` 卡片授权消费和受控副作用。
