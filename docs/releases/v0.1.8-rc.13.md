# v0.1.8-rc.13

## Breaking Changes

- 无。

## Features

- **Supervisor 启动自检 rc 通道配置**。若配了 `LAB_UPDATE_MANIFEST_URL`（stable 通道）却漏配 `LAB_UPDATE_PRERELEASE_MANIFEST_URL`，Bridge 启动时会在 stderr 打一行 `[warn] LAB_UPDATE_PRERELEASE_MANIFEST_URL 未配置`，提示 `/help` 卡片将不显示已发布的 rc 版本。此前"发了 rc → 用户 `/help` 看不到 → 反复追根因"的场景在启动时即可发现。两者都配或都未配则不打（后者已由 `/help` 卡片提示"self-upgrade disabled"，避免重复）。

## Bug Fixes

- 无。

## Upgrade Notes

- 无需迁移；仅在 supervisor 部署缺 prerelease URL 时新增一行 stderr warning，不影响运行时行为。
- 若不打算接收 rc，warning 可忽略；若打算接 rc，在启动脚本/systemd env 里补配 `LAB_UPDATE_PRERELEASE_MANIFEST_URL`（指向 prerelease 通道固定入口 manifest，具体 URL 参考 README 部署段），重启 supervisor，然后发 `/.devel 1` 开启开发者模式。
- README 部署段已补对应示例；self-loop 仓 `config/` 目录新增 `linux-supervisor.service` 与 `linux-supervisor.env.example` 模板，便于把 Linux 服务器 supervisor 迁到 systemd user unit 托管（该迁移由维护者手动执行，self-loop 不代跑）。
