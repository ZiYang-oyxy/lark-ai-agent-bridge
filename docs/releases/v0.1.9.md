# v0.1.9

## Breaking Changes

- 无。

## Features

- 新增 `TopicSeedMode` 偏好，topic 新话题默认走 quote 模式：不再 fork 主会话历史，仅用当前 @bot 消息正文与引用内容作 seed，长期使用避免上下文膨胀。
- 保留 fork 模式为可选项，`/config` 与 `/local-config` 的会话行为面板均可切换 quote/fork。
- 自升级重启后主动回到原对话报「升级成功」，用户不再需要手动确认新版本已生效。
- `/config` 元信息行改成 CardKit 真复选框，点击即生效并持久化，取消原有 select 与保存按钮。
- 配置面板整体打磨：所有 section 默认折叠、面板头填满卡片宽度；群里打开全局配置多一个直达按钮跳转该群局部覆盖。
- `release` 工具链的 `tag` 与 `publish` 可复用同一发布的 L1 测试凭证，脏 worktree 或指纹变化时自动重跑。

## Bug Fixes

- 流式卡片 status bar 显示实时 ctx 用量而非累计 tokens，本轮 sidecar 未落盘时回退到同 session 上一次已知占用并标注 approx。
- P2P 私聊在 topic 模式下也支持并行 @bot，每次 @ 独立 mint synthetic thread，不再串行排队。
- 图片生成任务要求最终响应包含 Markdown inline image 才算完成，禁止裸路径与仅口头声明。
- 无 preference store 的 fallback 路径补上 `TopicSeedMode` 默认值，`/config` 表单下拉不再落空。
- 群覆盖直达按钮在真实卡片里可见，独立 CardKit 按钮改用 `element_id` 保留 `local_config.edit` 回调。
- Codex 卡片保留 process messages，避免运行中信息被清空。
- Release 工具链指纹覆盖 `GOTOOLCHAIN` 实际选择的 Go binary、compiler、linker SHA256，不再仅校验 launcher。

## Upgrade Notes

- 无需迁移。topic 模式默认从 fork 切到 quote，需要保留 fork 行为的用户请在 `/config` 或 `/local-config` 显式选择 fork。
- 运行中卡片 status bar 会显示 `~ctx: XX%`（approx）或 `🟢 ctx: XX%`（fresh），终态卡片仍为本轮真值。
- 远端 `v0.1.9-rc.5` tag 指向的 commit 不在 main 上，请勿用它执行 publish；升级请使用 `v0.1.9`。

## Miscellaneous

- `tasks.md` 清理已完成的 Codex 卡片相关待办条目。
