# v0.1.15-rc.6

## Breaking Changes

- 无。

## Features

- `/cron add` 与 `/timer add` 的任务确认卡新增 60 秒逐秒倒计时。倒计时期间仍可手动确认或取消；超时未操作时自动创建任务，并把原卡更新为按钮禁用的“定时任务已自动创建”。
- 自动确认截止时间与终态通知状态持久化：Bridge 重启后会先恢复到期确认，终态卡更新失败时降级发送独立通知，通知失败则在后续轮询中重试。

## Bug Fixes

- CardKit 卡片统一使用会话可用宽度，改善宽表格、长文本和命令卡片的展示空间。
- `/config` 每次渲染时重新读取 `agents.json` 的 Agent 选项，修改 Agent 描述或目录后无需重启 Bridge 即可在配置卡中生效；文件缺失或格式错误时保留启动时快照。

## Upgrade Notes

- 无。

## Miscellaneous

- 增加自动确认、提前取消、确认/取消竞争、终态通知 fallback、跨重启重试和渲染阻塞下取消响应的回归覆盖。
- 补充 CardKit 全宽输出的设计与实施记录。
