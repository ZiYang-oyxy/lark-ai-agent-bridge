## Features

- `/help` 的「查看更新」详情卡现在展示当前版本到目标版本之间**所有差异版本**的 release note，按由新到旧依次拼接（每段带 `## v<version>` 分节标题、以 `---` 分隔），卡片标题相应改为「v<当前> → v<目标> Release note」。此前跨多个 rc 升级时只显示目标版本一份 notes，中间版本的变更不可见。中间版本 notes 取不到时会跳过（记 `update_notes_skipped` audit），不影响整卡；跨大版本或版本不可枚举时优雅降级为仅显示目标版本。
