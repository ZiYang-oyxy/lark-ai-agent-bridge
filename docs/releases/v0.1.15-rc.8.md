# v0.1.15-rc.8

## Breaking Changes

- 无。

## Features

- 引用消息现在优先显示 `姓名(open_id)`，让 Agent 能同时理解发送者姓名并保留可追溯的稳定 ID。消息接口未返回姓名时，Bridge 会使用当前会话成员信息补全；查询失败则自动降级为原始 `open_id`，不阻断消息处理。

## Bug Fixes

- 修复 Topic 后续消息反复注入根消息引用的问题。引用正文、发送者和附件现在只进入 Topic 首轮 seed；普通 Chat 中用户每次显式引用的行为保持不变。
- 修复单条陈旧或不合法偏好导致 Bridge 无法启动的问题。启动时会丢弃无法恢复的覆盖项并记录审计，合法配置继续生效；全局配置更新时也会主动收敛不兼容的群级覆盖。

## Upgrade Notes

- 无需迁移配置。存在陈旧偏好时，升级后的首次启动可能记录配置降级审计；原始配置文件不会在读取阶段被自动改写。

## Miscellaneous

- 补充引用发送者解析的分页、正负缓存、容量边界与失败降级测试，以及 Topic 首轮 seed 和偏好恢复的回归覆盖。
