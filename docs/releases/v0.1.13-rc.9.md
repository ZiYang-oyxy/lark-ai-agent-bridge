# v0.1.13-rc.9

## Breaking Changes

- 无。

## Features

- 新增管理员命令 `/config set key=value ...`，可直接修改全局运行偏好；`agent_home=`、`agent_bin=` 和 `meta_rows=` 支持显式清空。
- 新增群级 `/local-config set key=value|inherit ...`，可增量修改本群覆盖，使用 `inherit` 恢复继承全局配置。
- 新增管理员命令 `/mkdir <path>`，仅允许在配置的 workspace 根目录内创建目录。
- `/cron` 与 `/timer` 支持 `confirm|cancel [draft-id]`，可在当前会话确认或取消待处理草稿；`/help` 已补齐相关说明。
- 扩展本地 smoke、simulate 和真实 E2E case 清单，并记录 profile、channel、strict L3 等发布回归证据。

## Bug Fixes

- `/mkdir` 在解析目标前固定 workspace root，阻止符号链接替换把目录创建重定向到 workspace 外。
- 全局与群级配置写入改为原子更新；配置卡片携带 revision，检测到并发修改时要求重新打开，不再静默覆盖其他管理员的变更。
- 配置保存结果只显示本次实际变化的字段；`/local-config set` 会拒绝大小写不敏感的重复字段。
- 引用或转发素材进入 Agent prompt 时，用户当前指令保持在前，避免长素材削弱本轮主请求。
- doctor preflight timeout 支持受限覆盖，降低高负载环境中的误判，同时保持超时上限。
- RC 发布回归 evidence 会从规范版本号推导 `rc`/`stable` channel，不再固定写成 `stable`。

## Upgrade Notes

- 这是 RC，只更新 prerelease 通道，不影响 stable 通道。
- 需先在 `/help` 开启开发者模式，再使用升级按钮安装此 RC；升级动作仍由用户手动触发。
- 配置卡片若在其他配置变更之前已打开，保存时可能提示配置已更新；重新打开 `/config` 或 `/local-config` 后再保存即可。

## Miscellaneous

- 抽取 shell assert 与 simulate suite 公共库，减少 smoke/verify 重复实现。
- 更新测试工作流、加用例 SOP、L3 sender 表述与引用 prompt 顺序断言。
