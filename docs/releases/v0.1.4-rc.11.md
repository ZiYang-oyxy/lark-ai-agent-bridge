## Bug Fixes

- codex 兜底 bin 与 claude 对称，修复 `exec: "codex" not found in $PATH`：会话未选定 codex bin 时，`resolveAgentBinHome` 原先硬编码回退到裸名 `codex`，依赖运行进程 PATH；而 bridge 服务进程 PATH 不含 workspace bin 目录，导致 codex 运行失败（claude 因有 `LAB_CLAUDE_BIN` 提供可配置的绝对路径兜底而正常）。现新增对称的 `Config.CodexBin`（默认 `codex`，可由 `LAB_CODEX_BIN` / `E2E_CODEX_BIN` 覆盖成绝对路径）作为 codex 兜底。零值 Config（未走 LoadFromEnv）仍退回裸名，不劣于原行为。

## Upgrade Notes

- 仅当部署环境为 codex 配置了 `LAB_CODEX_BIN` 时生效；未配置则行为不变（仍用裸名 `codex`）。codex wrapper 定位真实 Codex CLI 所需的运行时 PATH 属部署侧配置，不在本次代码变更范围内。
