# v0.1.11-rc.1

## Breaking Changes

## Features

- **三段布局卡片省略提示**：思考过程/工具调用总轮次超过2时，折叠面板顶部自动添加斜体提示「（已省略前面 N 轮思考过程，仅显示最近 2 轮）」/「（已省略前面 N 次工具调用，仅显示最近 2 次）」，明确告知用户前面内容被折叠，避免误解为内容丢失。
- **工具调用区排版优化**：移除工具调用名称、命令块、输出块之间的多余空行，整体排版更紧凑，减少垂直空间占用。

- 工具区格式调整不影响命令和输出内容，仅优化空白间距。
