# v0.1.13-rc.4

## Breaking Changes

- 无。

## Features

- 新增管理员 `/upgrade` 命令：默认升级当前通道的最新版本；开发者模式可用 `/upgrade stable` 或 `/upgrade rc` 明确选择正式版或 RC 通道，沿用既有下载校验、回滚与受控重启链路。

## Bug Fixes

- 修复运行中卡片每 5 秒 heartbeat 全卡刷新时正文未受预览上限约束的问题：此前后续普通流更新会将同一卡片截断，造成客户端在长正文和少量行之间闪烁；现在 heartbeat 与普通流更新使用相同的正文预览策略，仍会刷新耗时与运行状态。
