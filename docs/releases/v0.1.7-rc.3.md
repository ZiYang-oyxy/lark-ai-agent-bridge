# v0.1.7-rc.3

## Breaking Changes

- 无。

## Features

- Topic 会话模式下，话题 session 首次执行时会用 Claude 官方 `--fork-session` 从主 session 分叉出一份新的 Claude session，让话题 session 首轮就拥有主消息里的全部上下文。之后两个 session 各走各的 AgentSessionID，互不污染，恰好符合"两边有起点上下文但独立演化"的产品语义。
- Codex 分支暂不参与 fork：Codex CLI 目前只有 TUI 版 fork、没有 headless 命令，行为与原来完全一致，等 `codex exec fork` 出来再补。

## Bug Fixes

- 修复 topic 模式下主消息与它衍生的话题内回复上下文完全断裂的问题（用户在主对话说过的内容，进话题后 Claude 完全看不到，反之亦然）。

## Upgrade Notes

- 无需迁移配置。已存在的话题 session 若已有自己的 AgentSessionID 会继续按老行为走；仅新创建的话题 session 触发 fork。

## Miscellaneous

- 新增单测覆盖 fork 命令拼接与 `forkSeedForTopicSession` 六种边界；L3 真机验证通过（主消息记住的宠物名在话题内提问被正确回答，且主 session 未被污染）。
