# v0.1.11-rc.3

## Breaking Changes

- 无。

## Features

- `append` 回复模式对齐参考 bridge 的轻量消息卡片：隐藏 COT 正文，工具调用只显示状态、工具名和安全摘要，不显示工具输出；Claude 与 Codex 使用一致的可见格式。
- 超长 `append` 卡片采用连续尾部窗口，较早内容超限时显示省略提示，优先保留最新工具状态、最终正文和终态信息。

## Bug Fixes

- Codex 工具结果即使没有 stdout，也会把工具状态从执行中更新为成功或失败，避免终态残留 `⏳`。
- CardKit 序列化接近 28 KiB 限制时按实际 JSON 字节收缩尾部窗口，避免最新内容被旧内容挤掉或退化成通用应急卡片。

## Upgrade Notes

- 无需迁移；已有 `reply_mode=append` 配置升级后自动使用新卡片效果。
- `append-clean-card` 与 `latest-card` 行为保持不变。

## Miscellaneous

- 已通过 L1 全量测试、L2 超限 payload 测试，以及 Claude/Codex 真实飞书卡片验证；9500 字协议输出已真实经过 Test、CardKit 和飞书终态回读。
