# v0.1.8-rc.4

## Bug Fixes

- **进行中卡片重新看得到上下文用量**。之前 `agentCardStream` 只在 Start 时通过 `metaForRun` 一次性读 sidecar 快照，`Handle` 期间从不刷新 `Ctx*` 字段；首轮新会话 `sess.AgentSessionID` 为空时 `contextusage.Read` 直接返回空 Usage，卡片 meta 行的 ctx 段落缺失，fallback 到累计流水 token，用户看不到"上下文用量"。现在 Handle 每帧调用 `refreshContextUsageLocked`：只要本轮已知 SessionID 就 `ReadAfter(runStartedAt)` 拿本轮 fresh 值升级 `s.meta.Ctx*` 并置 `CtxApprox=false`；读失败什么都不改，保留起始 approx 显示不闪烁。`metaForRun` 起始 meta 从上一轮 sidecar 读到的旧值统一标 `CtxApprox=true`（渲染带 `~` 前缀），与刷新后的本轮 fresh 视觉区分。`Finish` 覆盖也补上 `CtxApprox`，避免 `postRunMeta` 拿到 fresh 后终态卡片仍带 `~`。
