# v0.1.4-rc.15

## Breaking Changes

- 无。

## Features

- 回复卡片元信息行改为可配开关，`/config`（全局）与 `/local-config`（本群覆盖）均可设置：rc 早前的 462333f 无条件隐藏了 AI 回复卡片底部两行运行时元信息（agent/会话/模型/ctx/tokens 与 user/ip/workdir）。现改为 `ShowMetaRows` 开关控制，**默认隐藏**（对现有部署零行为变化），需要时可在全局或按群开启。全局在 `/config`、本群覆盖在 `/local-config` 的「元信息行」下拉里切换；本群设置不影响全局与其它群。

## Bug Fixes

## Upgrade Notes

- 默认行为不变（元信息行仍隐藏）。升级后如需展示，在 `/config` 或 `/local-config` 把「元信息行」设为「显示元信息行」，下一条新消息生效。注意开启后会把 user/ip/workdir 暴露到聊天，按需选择作用范围（建议只在需要的群用 `/local-config` 开启）。
