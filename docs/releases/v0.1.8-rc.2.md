# v0.1.8-rc.2

## Bug Fixes

- **`lark-bridge-release tag` 允许 release notes 省略无内容的 section**。之前 5 段（Breaking Changes / Features / Bug Fixes / Upgrade Notes / Miscellaneous）全部强制存在，缺一段就报 `line N must be section "..."`，无内容的段只能写 `- 无。` 占位。现在改成"出现的段仍按模板顺序、缺失的段可以直接省略"——顺序错误 / 段内空 bullet / bullet 前有正文 / 重复 bullet / 混合 `- 无。` 与其他 bullet 等既有校验保持不变；发布本身只要至少一段有内容就允许。渲染器 `renderReleaseNotes` 自动产出的 notes 仍写全 5 段（占位美观），只放宽手写 notes 通过 tag 时的校验。
