# v0.1.11-rc.4

## Breaking Changes

- 无。

## Features

- 运行中的 `append`、`append-clean-card` 和完整运行卡片将停止按钮移动到顶部标题行最右侧，标题与停止操作保持同一视觉层级。

## Bug Fixes

- 修复 `append` 轻量 Markdown 卡片遗漏停止按钮的问题。
- 停止按钮继续复用原有二次确认、callback 和终态 disabled 逻辑，避免正文底部重复渲染。

## Upgrade Notes

- 无需迁移；已有回复模式配置会自动使用新的停止按钮布局。

## Miscellaneous

- 已通过相关 CardKit、Bridge 单元测试和真实 Test 卡片链路验证。
