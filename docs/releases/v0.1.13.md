# v0.1.13

## Breaking Changes

- 无。

## Features

- 新增管理员 `/upgrade` 命令：默认升级当前通道最新版本，开发者模式可 `/upgrade stable` 或 `/upgrade rc` 明确指定通道，沿用既有下载校验、回滚与受控重启链路。
- 新增管理员 `/config set key=value ...`，直接修改全局运行偏好；`agent_home=`、`agent_bin=`、`meta_rows=` 支持显式清空。
- 新增群级 `/local-config set key=value|inherit ...`，增量修改本群覆盖配置，`inherit` 恢复继承全局；`local_config.reset` 也可在群里通过消息触发。
- 新增管理员 `/mkdir <path>` 命令，仅允许在配置的 workspace 根目录内创建目录。
- `/cron` 与 `/timer` 支持 `confirm|cancel [draft-id]`，可在当前会话确认或取消待处理草稿。
- 群里普通消息通过 `/action` 触发的对等命令与卡片点击行为对齐，权限与副作用共用同一套白名单。
- 引用消息按发送者主体分档标注：来自另一 bot、来自自己历史、来自普通用户，避免 Agent 把外部第一人称当作自身历史。
- 话题模式处理顶层 post 时先创建并绑定话题再启动 Agent，保证后续回复稳定进入同一话题。
- 配置持久化底座上线：凭据白名单 `LAB_LARK_*` 环境变量、Config 分区段落盘、secret 只驻内存、`--reset-store` 出厂重置。
- `/status`、`/help` 与升级卡片显示 rc 通道来源，方便区分开发者模式与正式版。
- 新增 Agent 请求与飞书入站原始日志：Bridge 在调用 Agent 前将最终 Prompt、模型、effort、工作目录写入 `<workdir>/.lark-agent-bridge/agent-requests.jsonl`，长连接事件和卡片回调原始 payload 写入 `feishu-events.jsonl`，均使用 `0600` 权限，写入失败只记录 audit 不阻断消息处理。

## Bug Fixes

- 修复 `/config` 状态栏元信息行三个开关未能可靠保存的问题，关闭其中一行现在会持久化为 `false`；兼容已打开的旧版配置卡片仍能解析 CardKit 多选返回的对象形式值。
- 运行中卡片不再展示同一会话上一轮的模型或上下文数据，当前轮数据就绪前会显示同步状态；Codex 运行中会从 session transcript 读取实际生效模型并随流事件刷新，续聊也采用最新一条模型记录，避免配置变更后仍展示旧轮模型。
- 修复运行中卡片 5 秒 heartbeat 全卡刷新时正文未受预览上限约束的问题：heartbeat 与普通流更新现在使用相同的正文预览策略，卡片不再在长正文和少量行之间闪烁，仍会刷新耗时与运行状态。
- 修复 P2P 场景下“转发素材 + @bot”产生两条独立回复的问题：转发素材延后与后续 @bot 请求合并交给 Agent。
- 修复群 `mention_only` 下“合并转发 + @bot”读不到转发正文的问题；直接接收的合并转发也会主动展开内容，读取 CardKit 可见文本与附件上下文。
- 引用飞书卡片时保留跳转按钮和链接的真实 URL：按钮渲染为 `[按钮:文本](url)`、link 渲染为 `[label](url)`，兼容 legacy 与 CardKit v2；可展开表格、标题、字段等元素，“先转发卡片、再回复同一卡片”不再把相同内容重复发给 Agent。
- 引用图片元素时保留 `image_key`，呈现为 `[图片 image_key=<key>]`，便于 Agent 按 key 拉取原图做 OCR 或转存。
- 修复群里跨分身/跨主体的引用消息把“我起了子代理”这类第一人称叙述带入当前会话导致的幻觉。
- 引用或转发素材进入 Agent prompt 时，用户当前指令保持在前，避免长素材削弱本轮主请求。
- 修复大段日志或引用导致 Claude 启动时报参数过长的问题；Agent 上游中断时保留已有输出并提示可重新发送。
- 修复 `/action` 消息路径下 CardKit 首次渲染缺 `replyTo` 导致按钮无响应。
- 修复 markdown 分页场景下“停止”按钮返回操作失效，取消也能可靠中止。
- 修复 coder / worker 模式回复归类错乱。
- 思考与工具省略提示并入折叠标题，减少卡片两行占用。
- Status Bar 按 SemVer 判断更新，避免旧版本倒挂提示。
- `/mkdir` 在解析目标前固定 workspace root，阻止符号链接替换把目录创建重定向到 workspace 外。
- 全局与群级配置写入改为原子更新，配置卡片携带 revision，检测到并发修改时要求重新打开，不再静默覆盖其他管理员的变更；配置保存结果只显示本次实际变化的字段，`/local-config set` 会拒绝大小写不敏感的重复字段。
- doctor preflight timeout 支持受限覆盖，降低高负载环境中的误判，同时保持超时上限。
- RC 发布回归 evidence 从规范版本号推导 `rc`/`stable` channel，不再固定写成 `stable`。

## Upgrade Notes

- 无需迁移，重新打开 `/config` 即可使用新的状态栏元信息行开关；新发起的 Codex 任务会自动显示运行期实际模型。
- 群消息接收配置保持不变：机器人不会因合并转发展开而响应群内所有合并转发，仍需通过 @ bot 触发。
- 配置卡片若在其他管理员变更之前已打开，保存时可能提示配置已更新；重新打开 `/config` 或 `/local-config` 后再保存即可。
- `agent-requests.jsonl` 与 `feishu-events.jsonl` 包含完整消息与 Prompt，排障结束后请按实际环境的访问控制与磁盘策略管理。

- 补充测试框架总体设计、YAML 框架、L3 checklist、P-VERIFY / P-OBSERVE / P-ENV 三个专项演进方案及 PR 门禁文档。
