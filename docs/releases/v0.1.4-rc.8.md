## Features

- 运行完成时通知发起人（opt-in）：当一次 run 到达「已完成」终态时，除原地更新终态卡外，额外补发一条 thread reply 新消息以产生飞书红点提醒；群聊中 @ 发起人，私聊直接提醒。由偏好 `NotifyOnComplete` 控制，默认关闭，可在 `/config` 表单的「完成通知」下拉开启。终态卡原地更新不产生红点，故以补发新消息作为提醒手段；补发失败仅记 audit，不阻断主流程。
