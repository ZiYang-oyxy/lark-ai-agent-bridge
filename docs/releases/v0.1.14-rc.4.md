# v0.1.14-rc.4

## Breaking Changes

- 无。

## Features

- 新增 `doctor --strict --online --json`，可在有界超时内验证飞书凭据和 Bot 身份，并输出不含凭据的结构化检查结果。
- 新增 `LARK_APP_ID_FILE` / `LARK_APP_SECRET_FILE` 及对应 `LAB_LARK_*_FILE` secret-file 配置；`serve` 增加同主机 App ID 摘要锁，避免两个进程重复消费同一 App 的长连接事件。
- tag workflow 自动构建 Linux x86-64 与 macOS ARM64、发布 GitHub Release、回读校验 binary，再最后更新 GitHub Pages channel manifest。

## Bug Fixes

- Feishu SDK `Info` 日志保留连接状态，但 WebSocket URL query、ticket、token、signature、Authorization 和 App secret 会在写入 stderr 前脱敏。
- RC bundle 只更新 `prerelease`，正式 bundle 只更新 `stable`，修复 RC 意外覆盖 stable manifest 的发布风险。
- Go cache 与 release test evidence 移出源码树；证据写失败测试不再依赖非 root 权限语义，可在 root、只读 checkout 和不同源码 owner 下稳定执行。
- release workflow 支持失败后幂等重跑，不会因 Release 已存在或 channel 内容无变化再次失败。

## Upgrade Notes

- 接收本 RC 时配置 `LAB_UPDATE_PRERELEASE_MANIFEST_URL=https://ziyang-oyxy.github.io/lark-ai-agent-bridge/prerelease/manifest.json`，并在飞书中发送 `/.devel 1` 开启 prerelease 通道。
- 现有直接环境变量配置继续兼容且优先于 secret file；secret file 必须是当前用户拥有、组和其他用户不可访问的普通文件。

## Miscellaneous

- 完成公开仓库历史与发布说明收口。
