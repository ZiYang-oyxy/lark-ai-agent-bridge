## Bug Fixes

- 修复工具调用在回复卡片过程区里的流式布局竖排乱码。Claude 流式输出中，工具（如 Bash）的调用参数经 `input_json_delta` 事件以 `partial_json` 分片到达，单片是未闭合的 JSON 碎片（如 `{"com` / `mand": "`）。此前这些碎片被当作过程区文本逐片追加，飞书在窄的折叠面板里按字符硬折行，渲染成竖排乱码。现改为丢弃这些增量碎片：完整的工具参数仍由完整 content block 与任务终态经代码围栏正确呈现。同时修复流式初帧工具参数为空对象时产出的空「1 行代码 `{}`」块。
