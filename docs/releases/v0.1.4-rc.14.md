# v0.1.4-rc.14

## Breaking Changes

- 无。

## Features

- 强化 v2 运行时指令对「自然语言定时意图」的引导：明确规定唯一可靠的定时途径是 `schedule propose` 提案，并显式禁止用 Agent 自带的会话内调度手段（内建 cron / 定时唤醒工具如 CronCreate、ScheduleWakeup，后台 `sleep` 轮询、常驻循环、`at`/系统 `crontab`、改文件模拟定时）来实现定时。此前指令只禁了 `sleep`/`at`/系统 `cron`，未覆盖 Agent 内建调度工具——Agent 可能选用其一，而这类工具依赖当前会话持续存活轮询、会话结束即失效、到点根本不触发。新指令并说明了原因（Bridge schedule 由独立进程持有、到期自动拉起全新会话，跨会话可靠），使无上下文的新会话也能自行做对判断。

## Upgrade Notes

- 纯运行时指令文本改进，无行为/接口变更。升级后新会话遇到定时类需求会被稳定引导走 `schedule propose` 提案与确认卡。
