# v0.1.9-rc.3

## Breaking Changes

- 无。

## Features

- **`/config` 元信息行改成点即生效的真复选框**。三个开关（Agent 行 / 主机信息行 / 开发者行）重新用飞书 CardKit `checker` 组件呈现真复选框视觉，且**脱离 form.submit**——每个 checker 挂独立 callback，点击触发新的 `config.toggle_meta_row` action：bridge 端读当前偏好、翻转对应字段、持久化、返回终态提示。用户点即生效，无需再按"保存"。适用范围：仅**全局 /config 卡**；`/local-config`（群覆盖）仍走 select_static + form.submit 不动，因为群覆盖是 `*bool` 三态（nil 继承 / true / false），"点击即翻转" UX 需单独设计。

## Upgrade Notes

- 无需迁移。checker 与 select_static 使用完全一样的 `show_meta_row_{agent,runtime,developer}` bool 字段名，preference schema 不变；旧配置无损接续。
