- 卡片脚标区分 agent 客户端并显示 session id：原先 Claude 与 Codex 在脚标处共用同一个 `🤖` 前缀加 agent 名字，无法一眼区分是哪个 agent。现按 agent 类型区分 emoji 并在原 agent 位置显示 session id 前 6 位——Claude 用 `🍊`、Codex 用 `⚙️`，例如 `🍊 73095b`。尚未建立 session id 时（首轮之前或执行失败）回退为 emoji 加 agent 名字，如 `🍊 Claude`、`⚙️ codex`。
