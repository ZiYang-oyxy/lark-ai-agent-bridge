# v0.1.3-rc.2

## Breaking Changes

- 无。

## Features

- 新增 L0–L3 分层回归编排、秒级本地 smoke 和远程 Test 验证入口，缩短发布前反馈周期。
- 飞书结果卡片可读取 Claude/Codex sidecar 的当前上下文窗口占用率，并展示绿、黄、红容量风险提示。
- 补充 timer 与 cron 命令帮助，并在 Agent 执行失败时保留有界诊断尾部，便于定位故障。
- 新增真实上下文 canary 场景，覆盖 Test workspace exporter overlay 的事务化验证。

## Bug Fixes

- 修复合法 Agent 偏好被 doctor 误判为无效配置的问题。
- 拒绝过期或跨 run 的 sidecar，避免结果卡片显示上一轮上下文数据，并优先使用当前 Codex token 数据。
- 隔离 scheduled、proposal 与 task Agent 会话，避免不同调度任务串用上下文。
- 修正真实 Agent 步骤的超时边界、重复 Release Note 生成和冗余更新提示。

## Upgrade Notes

- 更新 Test 或其他远程实例时，需要同时更新 Bridge 二进制与 workspace 的 `bin/claude`、context exporter、statusline；仅更新二进制会回退到估算用量。
- 替换二进制并重启服务即可，无需迁移持久化数据。

## Miscellaneous

- 完善两级验证流程与三个回归入口文档，明确本地 smoke、发布候选验证和远程 Test 冒烟的边界。
- 远程 server smoke 仅接受已发布 RC，并统一 L3 timeout 与 runner schema。
