# v0.1.5

## Breaking Changes

- 无。

## Features

- 运行完成时通知发起人（opt-in）：一次 run 到达「已完成」终态时，除原地更新终态卡外，额外补发一条 thread reply 新消息以产生飞书红点提醒；群聊中 @ 发起人，私聊直接提醒。由偏好 `NotifyOnComplete` 控制，默认关闭，可在 `/config` 表单的「完成通知」下拉开启。
- 卡片脚标区分 agent 客户端并显示 session id：按 agent 类型区分 emoji 并显示 session id 前 6 位——Claude 用 `🍊`、Codex 用 `⚙️`（如 `🍊 73095b`）；尚未建立 session id 时回退为 emoji 加 agent 名字（如 `🍊 Claude`）。
- 回复卡片元信息行改为可配开关：`ShowMetaRows` 控制底部两行运行时元信息（agent/会话/模型/ctx/tokens 与 user/ip/workdir），**默认隐藏**（对现有部署零行为变化）。全局在 `/config`、本群覆盖在 `/local-config` 的「元信息行」下拉里切换。
- `/help`「查看更新」详情卡展示当前版本到目标版本之间**所有差异版本**的 release note，按由新到旧拼接（每段带 `## v<version>` 分节标题、`---` 分隔），标题改为「v<当前> → v<目标> Release note」；中间版本 notes 取不到时跳过并记 `update_notes_skipped` audit，跨大版本或不可枚举时降级为仅显示目标版本。
- 强化 v2 运行时指令对「自然语言定时意图」的引导：明确唯一可靠途径是 `schedule propose` 提案，并显式禁止 Agent 自带的会话内调度手段（内建 cron / 定时唤醒工具、后台 `sleep` 轮询、常驻循环、`at`/系统 `crontab`、改文件模拟定时），并说明原因（Bridge schedule 由独立进程持有、到期自动拉起全新会话，跨会话可靠）。

## Bug Fixes

- 修复自升级点「升级」后二进制已替换但进程不重启、版本漂移的问题：旧实现从后台 goroutine 调用 `syscall.Exec`，在多线程 Go runtime 的非主 goroutine 下不可靠会静默失败。改为 `detachRestart`（`os.StartProcess` 拉起新进程后退出当前进程），跨平台可靠；重启失败时解除维护态并推送红色失败卡片，提示已回滚、可重试，不再停留在误导性的「正在重启」卡片。
- 修复上下文用量卡片首帧误退到累计流水 token：首帧渲染时本轮侧车尚未落盘会误判 stale。现改为拿不到本轮新鲜值但同 session 存在上一次合法占用时沿用并标注近似，渲染 `🟢 ~ctx: X%` 而非误导性流水 token；跨 session 仍拒绝复用。
- 修复跑着 rc 版本的实例在默认 stable 通道下看不到升级到同 core 正式版的提示：改为按 SemVer 语义（prerelease 严格小于其对应 release）比较。「rc 目标不进 stable 通道」的安全边界不变。
- 修复工具调用在回复卡片过程区里的流式布局竖排乱码：Claude 流式 `input_json_delta` 的 `partial_json` 碎片被当作过程区文本逐片追加、在窄折叠面板里硬折行成竖排乱码。现改为丢弃增量碎片，完整工具参数仍由完整 content block 与终态经代码围栏呈现；同时修复初帧空对象产出的空「1 行代码 `{}`」块。
- 会话启动阶段占位文案从「正在执行 Claude 请求...」改为「思考中…」：Claude/Codex 共用统一占位，不暴露底层 agent 执行细节。
- codex 兜底 bin 与 claude 对称：新增 `Config.CodexBin`（默认 `codex`，可由 `LAB_CODEX_BIN` / `E2E_CODEX_BIN` 覆盖成绝对路径），修复 bridge 服务进程 PATH 不含 workspace bin 目录时的 `exec: "codex" not found in $PATH`。

## Upgrade Notes

- 无破坏性变更，默认行为与 v0.1.4 一致：完成通知、元信息行均默认关闭/隐藏，需要时在 `/config`/`/local-config` 开启。
- 本次升级即验证自升级重启修复：升级完成后进程 PID 会真正变化，可用 `/help` 或 `/status` 确认版本已切换。
- 开启元信息行会把 user/ip/workdir 暴露到聊天，建议只在需要的群用 `/local-config` 开启。

## Miscellaneous

- 新增 `detachRestart` 成功 / 启动失败路径、定时意图 catalog 契约等单元测试。
