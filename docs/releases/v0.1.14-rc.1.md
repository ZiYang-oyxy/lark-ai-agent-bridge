# v0.1.14-rc.1

## Breaking Changes

- 无。

## Features

- **命令面板新增关闭按钮**：`/help`、`/status`、`/config` 等大型命令卡片增加显式关闭动作，聊天历史更清爽。

## Bug Fixes

- **飞书 tenant_access_token 失效自动刷新**：租户 token 被服务端主动拒绝时立即重新签发并重试，避免长时间静默 401 导致的消息发送失败。
- **恢复列表展示短 session ID**：`resume` 卡片改用 8 位短 ID，长 ID 折叠在详情中，卡片密度显著改善。
