# v0.1.8-rc.3

## Features

- **升级失败卡片附「占用中的会话」清单**。之前 `/help` 升级按钮遇到"有任务正在运行或排队"只显示一句提示，用户无从下手判断哪些会话在挡。现在 busy 卡片会追加一个 markdown 表格：`# / Agent / Chat / 工作目录 / 状态 / 最近活跃`，`state` 分 `running` / `running (queued=N)` / `pending confirm`；`ChatID` 做前 4/后 4 缩略脱敏。快照与 busy 判定共用一段临界区，展示数量与 audit（`update_busy` 附 `N session(s)`）一致。

## Bug Fixes

- **升级失败卡片不再是绿色**。之前 `renderUpdateMessage` 从不设 `HeaderTemplate`，走 `templateForEvent` 的 default 分支恒为 `"green"`——失败也是绿色，视觉上读作"成功"，掩盖了实际状态。现在按 severity 分类：`orange` 用户可自救（busy 挡升级 / 目标版本已变化 / 已有升级在进行 / release note 暂时读不到），`red` 真出错（未启用自升级 / 下载或校验失败 / 替换 binary 失败）。header 标题也一并明确（如 "⚠️ 升级已暂缓：有会话在跑" / "❌ 下载或校验失败"）。
