# v0.1.7-rc.6

## Breaking Changes

- 无。

## Features

- `/config` 表单恢复"推理深度"（effort）下拉选项，并允许 `/local-config` 逐群覆盖。运行参数分组末尾新增 effort select，四档 `default（跟随 Agent 默认） / low / medium / high`，`default` 显式标注"跟随 Agent 默认"以区分显式指定。全局保存时 `config.save` 用新增的 `isKnownEffort` 校验值是否在合法集合内，未知值触发 `config_save_failed` 审计并返回 error 事件、不落库；omit 时保留 current。per-chat 保存走 `chatOverrideFromForm`：读 `effort`，与全局值不同时写入 `ChatOverride.Effort`（该字段之前已存在但没被表单读）。`/local-config` 概览页多渲染一行"推理深度：<value> （本群）/（继承）"，让本群覆盖状态一眼可见。Model 保持不入表单（表单里 stale 提交的 model 一律忽略）。

## Bug Fixes

- 无。

## Upgrade Notes

- 无需迁移配置。旧 preference 快照对 effort 的存储路径不变，仅表单层重新暴露编辑入口；升级后原有全局 effort 值继续生效。
