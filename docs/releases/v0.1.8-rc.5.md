# v0.1.8-rc.5

## Features

- **/config 里 status bar 的开关拆成三个独立控制,并新增开发者行**。原来的单一「元信息行」开关一开就同时打开 agent 行(agent/会话/模型/tokens)与主机行(user/ip/workdir),两行只能整体显隐。现在 /config 里多出一个「📊 元信息行」section,提供三个独立下拉:「Agent 行」「主机信息行」「开发者行」,可以各自单开单关;`/local-config` 也支持按群独立覆盖每一个开关。**新增的「开发者行」**渲染 `<emoji> v<current> · ⬆️ 最新 v<latest>` 两段:前置 emoji 兼作版本通道指示——开发者模式(rc 通道)`🐞`,正式版通道 `🦋`,一眼能看出"当前跑在哪个版本、哪个通道"。最新版本号通过 update client 的内存缓存读取(cache-only、无 HTTP 请求),cache 冷时省"最新"段、显示 emoji + 当前版本即可。旧配置 `show_meta_rows: true` 自动迁移为 agent+runtime 两行同开(不含 developer,与旧版语义一致);schema 无需 bump,旧字段一次写入后自然消失。
