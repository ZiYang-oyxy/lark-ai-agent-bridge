# v0.1.11

## Breaking Changes

- 无。

## Features

- `append` 使用轻量卡片展示工具状态和安全摘要，减少冗余输出。
- 超长 `append` 可在 `/config` 开启自动续卡，最多保留九张尾部卡片。
- `append-clean-card` 以独立时间线展示思考与工具，最终回答保持居中。
- 合并转发会展开嵌套引用和可访问父消息，保留完整上下文。
- 运行中卡片 5 秒自动刷新，停止按钮固定在标题行右侧。

## Bug Fixes

- Codex 推理深度会正确传入命令行，并在卡片中显示实际值。
- 状态栏多选和显示开关恢复生效，保存后统一更新卡片。
- 工具没有 stdout 时也会正确收敛为成功或失败状态。
- 升级说明隐藏空白小节，状态栏可自动发现最新版本。
- 无权限读取引用父消息时会明确标记，不会中断回答。

## Upgrade Notes

- 无需迁移，现有回复模式和状态栏配置会自动沿用。
- 长 `append` 默认继续尾部截断，可在 `/config` 开启自动续卡。
