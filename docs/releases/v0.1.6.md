# v0.1.6

## Breaking Changes

- 无。

## Features

- `/help`「查看更新」的 release note 卡片新增「发布历史」外链按钮：开发者模式（`/.devel 1`，prerelease 通道）下指向 rc 发布历史页（`lark-ai-agent-bridge-rc-releases.html`，列全部含 rc 与正式版），普通用户指向 stable 发布历史页（`lark-ai-agent-bridge-releases.html`，只列正式版）。按钮对所有可见用户开放（只读外链，非 admin 亦可见）。

## Bug Fixes

- 无。

## Upgrade Notes

- 纯卡片增强，无配置或行为变更。升级后在 `/help` 查看更新时出现「发布历史」链接；链接域名与升级 manifest 同源自动推导，无需额外配置。

## Miscellaneous

- 发布历史页由发布流程自动刷新（`publish.sh` 集成 `releasing-lark-bridge` 生成器）：stable 页只列正式版、rc 页列全部；正式版发布刷两页、rc 发布刷 rc 页。
