## Bug Fixes

- 首轮卡片补齐 Session ID 与上下文余量：`agentCardStream.Handle` 现在会立刻采纳 stream 事件里带的 agent session id（Claude 的 `system.init.session_id`、Codex 的 `thread.started.thread_id`），`FinishTransformed` 也会从 `postRunMeta` 返回的 meta / result 兜底回填 SessionID。之前首轮卡片 footer 里 Session ID 一直是空、进而导致侧车按空 sessionID 查不到，`ctx: N%` 也一起丢失——现在首轮就能看到 6 位 Session ID 和上下文占用行。
