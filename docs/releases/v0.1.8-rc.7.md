# v0.1.8-rc.7

## Features

- **`/config` 的「📊 元信息行」section 收敛为三个真复选框,label 后带 mock 数据示例**。上一版 rc.5 用三个「隐藏/显示」下拉承载三行开关,视觉臃肿。本版切换到飞书 CardKit 2.0 官方 `checker` 组件,呈现三行原生复选框;每个 label 后直接展示 mock 数据示例——例如 Agent 行 label 是 `Agent 行 · 例：🍊 535a99 · 🧠 claude-opus-4-7[1m]（high） · 🟢 ctx: 35% (354.5k/1000k)`,主机信息行是 `主机信息行 · 例：👤 lijun.996 · 🖥️ 192.0.2.42 · 📁 /home/<USER>/ws`,开发者行是 `开发者行 · 例：🐛 v0.1.8-rc.7 · ⬆️ 最新 v0.1.8-rc.7（🐛 rc / 🦋 stable）`——用户扫一眼就知道开启后卡片底部长什么样,不必先勾一遍才能看到。
- **开发者模式指示 emoji 从 🐞 换成 🐛**,视觉上更贴近"bug/debug"直觉。开发者行渲染 `🐛 v<current> · ⬆️ 最新 v<latest>` 承载"当前版本 + 通道"两重信息:rc 通道 🐛、stable 通道 🦋。同步更新 /config 里的说明文案。
