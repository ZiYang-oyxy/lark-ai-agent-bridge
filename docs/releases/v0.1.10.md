# v0.1.10

## Breaking Changes

- 无。

## Features

- **三段布局（append-clean-card）下思考过程与工具调用滚动保留最后两段**：不再是单段反复刷新，最近两轮思考/两次工具调用用分隔线分开可见，更早内容自动折叠，既保留最近上下文又控制卡片长度。
- 累计计数（折叠标题「思考过程 × N」「工具调用 × N」）保持准确，统计全过程总轮次/总次数。
- 卡片容量适配逻辑优化：三段布局超长时优先收缩块内最旧内容，保留最新部分，避免直接删除整个过程块导致历史丢失。

## Bug Fixes

- doctor preflight 校验实际生效的 agent 可执行文件，避免配置与实际运行二进制不一致时误判健康。
- 修复 Codex 流式卡片 metadata 丢失问题。
- 修复话题模式下需要显式 @bot 才会响应的问题。
- 修复自升级动作未提前确认导致的响应延迟。
- 修复短会话 ID 因共享 UUIDv7 时间戳前缀都显示为相同前缀的问题，改为显示末 6 位区分不同会话。

## Upgrade Notes

- 无需迁移，升级后自动生效。
- 三段布局是默认回复模式，运行中思考区默认展开，可以看到最近两轮推理过程和两次工具调用。
- 点击折叠区标题仍可展开查看完整历史。

## Miscellaneous

- 单元测试覆盖滚动保留逻辑，所有测试通过。
- L3 端到端验证在测试群实测通过。
