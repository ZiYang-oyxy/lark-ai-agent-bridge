# v0.1.4

## Breaking Changes

- 无。

## Features

- 新增开发者模式与预发布（rc）升级通道：管理员发送隐藏命令 `/.devel 1` 开启、`/.devel 0` 关闭。默认关闭时行为与之前一致，仅跟踪 stable 通道。
- 新增隐藏命令 `/.todo <需求>`（不进 `/help`，admin-only）：把自然语言需求包装成 self-loop briefing，以 claude agent 身份触发 bridge 自我改进流程（分析 → 改源码 → 分层验证 → 回报）。
- 优化 `/help` 展示：拆分会话行并统一命令删除动词，信息更清晰一致。

## Bug Fixes

- 修复飞书卡片上下文用量在 fallback 路径下的误导显示：当 context-usage sidecar 不可用（`claude -p` one-shot 运行的常见情况）时，卡片改为语义明确的 `🔢 tokens: 本轮 X · 累计 Y`，并在单轮会话（累计等于本轮）时省略累计，避免把会话生涯累计 API 消耗误读为上下文爆表。`ctx: N%` 正常路径不变。
- 修复 stable 通道下跑着 rc 版本的实例在 `/help` 误报「暂时无法检查更新」，升级后正确显示「已是最新版本」；「rc 目标不进 stable 通道」的安全边界不变。

## Upgrade Notes

- 开发者模式默认关闭，普通用户仅跟踪 stable 通道，升级行为无变化。
- 开启开发者模式（`/.devel 1`）后，预发布通道 URL 由 stable manifest 自动推导（`-stable-` → `-prerelease-`），无需额外配置；`LAB_UPDATE_PRERELEASE_MANIFEST_URL` 仍保留为可选覆盖。rc 版本被视为可自升级的正式发布物，跑着 rc 的实例可继续升级到后续 rc 或正式版。
