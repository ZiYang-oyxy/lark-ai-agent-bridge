## Bug Fixes

- 引用飞书卡片时保留跳转按钮和链接的真实 URL：以前 quote 一张只含"标题 + 跳转按钮"的卡片（例如各种测试失败/告警通知），agent 拿到的正文里按钮完全被丢掉，无从跟进链接；现在按钮渲染为 `[按钮:文本](url)`、link 渲染为 `[label](url)`，兼容 legacy 与 CardKit v2 两种卡片形态。
- quote 图片元素时保留 `image_key`：图片会呈现为 `[图片 image_key=<key>]` 而非笼统的 `[图片]`，便于 agent 直接按 key 拉取原图做 OCR 或转存。
