## Bug Fixes

- **P2P 私聊在 topic 模式下也支持并行 @bot**。`sessionKeyForModeWithAlias` 之前 mint 每次 @ 独立 synthetic thread key 时要求 `msg.IsGroup && msg.Mentioned && msg.ID != ""`——`IsGroup` 这个 gate 让 P2P（1v1 DM）里的所有顶层 @bot 全部塌到 chat root 同一个 key、串行排队，即便用户显式选了 topic 模式（期望"每次 @ 都开新话题"）也无效。改为只看 `Mentioned && msg.ID != ""`：群聊行为不变（本来就 mint），P2P + topic + @bot 现在也能 mint 独立 `@bot:<msg_id>` synthetic thread，多次 @ 并发跑不再串行。触发条件依旧需要 `conversation_mode=topic`；chat 模式（默认）第一步 `mode != topic` 早退，不受此改动影响。

## Upgrade Notes

- 无需迁移。仅当用户在 P2P 里显式把 conversation_mode 切成 topic 时行为变化。已有 P2P 会话（chat 模式）不受影响。
