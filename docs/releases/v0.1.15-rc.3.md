# v0.1.15-rc.3

## Breaking Changes

- 无。

## Features

- Worker 模式的“思考推理”与“工具调用”默认收起，运行中和终态的卡片头部新增累计思考轮次、工具调用次数，例如 `💭 3 · 🔧 2 · ⏱ 18s`。Coder 与 Singleton 的既有展示策略不变。

## Bug Fixes

- 修复长 Coder 会话在早期内容超过预览上限后，后续思考和工具调用不再刷新的问题。流式预览现在滚动保留最新事件，终态仍保留完整收敛逻辑。
- topic 模式的 post 请求不再撤回预创建引导消息，避免飞书客户端留下“此消息已撤回”占位。
- topic 引导消息展示可复制的 Topic ID，便于定位话题路由和排查回复归属。

## Upgrade Notes

- 无配置迁移。RC 发布后，在已开启开发者模式的 supervisor `/help` 卡片中手动触发升级。

## Miscellaneous

- 补充 topic 引导与诊断行为的设计说明和回归测试。
