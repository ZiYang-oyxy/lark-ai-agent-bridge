## Bug Fixes

- 修复飞书卡片上下文用量在 fallback 路径下的误导显示：当 context-usage sidecar 不可用（`claude -p` one-shot 运行的常见情况，exporter 不写 sidecar）时，卡片从 `ctx: N%` 退回裸 token 行，原文案 `🔢 tokens: ▶ 本轮 / ∑ 累计` 中的 `∑` 是会话生涯累计 API 消耗（长会话可达千万级），被摆在上下文用量位置且无窗口参照，易被误读为上下文爆表。改为语义明确的 `🔢 tokens: 本轮 X · 累计 Y`，并在累计等于本轮（单轮会话）时省略累计。`ctx: N%` 正常显示路径不变。
