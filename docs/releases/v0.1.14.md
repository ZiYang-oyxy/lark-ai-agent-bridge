# v0.1.14

## Breaking Changes

- 无。

## Features

- **大型命令面板支持关闭**：`/help`、`/status`、`/resume`、`/config`、`/local-config` 和 `/agent-mode` 等卡片增加关闭动作，便于清理聊天历史中的操作面板。
- **转发与引用消息保留 @ 对象身份**：将飞书正文中的 `@_user_N` 占位符展开为可识别的姓名和 `open_id`；缺少姓名时仍保留稳定身份，Agent 可以准确识别被 @ 的对象。

## Bug Fixes

- **timer 和 cron 每次执行都创建新会话**：定时执行按稳定的 run ID 创建独立 Bridge session，不再复用同一任务上一次运行的 Agent session；同一次运行的失败重试仍保持幂等。
- **飞书 tenant_access_token 失效后自动刷新**：服务端拒绝旧 token 时立即重新签发并重试，避免消息收发因失效 token 持续失败。
- **Coder 长任务卡片持续更新**：跳过正文无变化的重复流式帧，只在内容实际变化或心跳触发时更新，避免卡片长时间停住、到终态才集中追赶。
- **恢复列表使用短 session ID**：`/resume` 卡片显示便于扫描的短 ID，完整 ID 仍用于内部恢复操作。

## Upgrade Notes

- 无需迁移配置或数据；升级后新触发的 timer 和 cron 会自动采用逐次独立会话。

## Miscellaneous

- 重构系统架构与测试框架文档，明确 Bridge 边界、执行链路、会话并发和扩展方式。
- 补齐 LICENSE、公开仓库说明和环境配置示例，清理仅适用于内部历史的材料。
