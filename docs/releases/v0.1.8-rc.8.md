## Features

- **`/help` 升级提示合并同一行**。发现新版本时，「✨ 发现新版本」不再单独占一行、下面另起一行加粗 `vCurrent → vLatest`；现在版本区间直接并入 section 标题，最终显示为「✨ 发现新版本 v0.1.8-rc.7 → v0.1.8-rc.8」这样单行，body 只保留「查看更新 →」按钮。
- **`/config` 与 `/status` 卡片顶部也显示升级提示**，视觉与 `/help` 完全一致（同款蓝框 section + 「查看更新 →」按钮）。仅在真正 `UpdateAvailable=true` 时挂，「已是最新 / 检查失败 / 未启用自升级」等低价值状态不挤占这两个卡片顶部。`/status` 卡的 refresh 按钮也走同一路径。实现上 `card.Event` 新增顶层 `VersionStatus *HelpVersionStatus` 字段、`BuildLarkCard` 在 status/config 分支 prepend 提示 element；抽 `versionStatus(ctx, sessionID)` helper 让三处入口共用 `s.Updates.Check` 检查逻辑。
- **`/config` 各段默认全部收起**。以往打开 `/config` 会一屏铺开 🤖 运行参数 / 💬 会话行为 / 👥 群消息 / 📊 元信息行 四段完整字段列表，现在这四段改为默认折叠的 collapsible panel，首屏只见标题、按需点开。访问控制段本就默认折叠，行为不变。
