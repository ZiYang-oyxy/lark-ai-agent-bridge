# v0.1.1

## Breaking Changes

- 无。

## Features

- 重新设计 `/help`、`/status` 和 `/resume` 卡片，按区块展示状态、帮助与恢复信息，并压缩会话记录行以提高可读性。
- `/help` 新增安全快捷按钮，可直接查看状态、恢复会话和打开群配置；其中版本状态与 `/status` 使用同一数据来源。
- 优化 `/config` 与 `/local-config` 卡片：配置按区块展示，局部覆盖采用“编辑后确认保存”的两步流程。

## Bug Fixes

- 修复群聊帮助卡片无法正确打开群配置的问题。
- 修复配置表单按钮与回调绑定不一致的问题。
- 修复 macOS ARM64 发布物格式检查误报失败的问题。

## Upgrade Notes

- 无需迁移现有会话、配置或工作区数据。
- 替换二进制并重启 Bridge 即可；一键升级会在存在运行中或排队任务时拒绝执行。

## Miscellaneous

- 发布件继续支持 `linux/amd64` 和 `darwin/arm64`。
