# v0.1.1

## 主要更新

- 重新设计 `/help`、`/status` 和 `/resume` 卡片，信息按区块展示，恢复记录更紧凑。
- `/help` 增加安全快捷按钮，可直接查看状态、恢复会话和打开群配置。
- 优化 `/config` 与 `/local-config`：按区块展示配置，局部覆盖采用“编辑后确认保存”的两步流程。
- `/help` 中的版本状态与 `/status` 使用同一套数据，避免显示不一致。

## 修复

- 修复群聊帮助卡片无法正确打开群配置的问题。
- 修复配置表单按钮与回调绑定不一致的问题。
- 修复 macOS ARM64 发布物格式检查误报失败的问题。

## 升级说明

- 支持 `linux/amd64` 和 `darwin/arm64`。
- 无需迁移现有会话、配置或工作区数据。
- 一键升级会短暂重启 Bridge；升级前存在运行中或排队任务时会拒绝执行。
