## Bug Fixes

- 话题模式下，"顶层 @bot → 从 bot 回复进入话题 → 话题内发第一条不 @bot 的消息" 这条动线不再被 intake 判成 `topic_not_participated` 而丢弃。根因是 `intake.go` 里 `mark := msg.Mentioned && msg.ThreadID != ""` 需要 `ThreadID != ""` 才 Mark 话题参与，而顶层 @bot 消息 `ThreadID` 为空，bot 用 `reply_in_thread=true` 回复后飞书分配的 `omt_*` id 从没被 bridge 学习，导致同话题内不 @bot 的下一条消息 `participated=false` 被 skip。修法：新增可选接口 `CardKitTopicJoinObserver`，CardKit renderer 在 reply 成功且 `replied.ThreadID != ""` 时通过 type assertion 上报 `(chatID, threadID, replyToMessageID, messageID, at)`；bridge 端 `TopicJoinObserver` wrapper 在 `RecordCardReply` 里同步调 `TopicParticipation.Mark` 并写 `topic_participation_auto_joined` 审计。终态补偿新卡路径同样触发通知；`cardkit_reply` 审计 detail 追加 `thread_id` 字段便于观测。
