## Features

- `/local-config` 编辑卡与 `/local-config set agent=<mode>` 现支持按会话覆盖 Agent mode；未设置时继续继承全局配置，使用 `agent=inherit` 可恢复继承。
- `/local-config` 概览会显示当前生效的 Agent mode 及其覆盖状态。切换 Agent 时自动清理不兼容的 `agent_home` / `agent_bin` preset，避免把原 Agent 的运行路径带入新 Agent。
